F1 Race Engineer —— 全量语音包（解压即用）
================================================

一、怎么用
  1) 双击【启动.bat】→ 自动打开浏览器面板（http://127.0.0.1:8765）
  2) 页面顶部会提示填 AI key（不填也能用「本地问答」：名次/圈速/油量/胎温/损伤/前车差距）
  3) 游戏内 设置 → UDP 遥测：
       UDP 遥测 = 开启
       UDP IP   = 127.0.0.1
       UDP 端口 = 20777
       UDP 赛制 = 2026（或与你游戏版本一致）
       “你的遥测”保持 = 受限  ← 改了可能收不到数据，需重启游戏

二、语音
  - 全量包已内置本地语音识别（faster-whisper + small 模型），无需联网、无需再下载。
  - 语音模式：双击【启动.bat】后，或在命令行运行：
       python.exe voice_main.py
     游戏中按【小键盘 0】说话：按一下开始，再按一下结束。
  - 不知道麦克风/耳机叫什么名字：
       python.exe voice_main.py --list-audio
     然后把名字片段填进 .env 的 AUDIO_INPUT / AUDIO_OUTPUT，或在网页【设置】里切换。

三、需要联网的部分
  - AI 问答（除本地快答外）需要你填一个 OpenAI 兼容的 API key（DeepSeek 等）。
  - 本地语音识别本身完全离线，不需要联网。

四、解压即用的含义
  - 所有配置(.env)、会话记录(sessions/)都保存在本目录，删掉整个文件夹即卸载。
  - 首次运行若双击没反应，请看本目录是否被杀毒软件隔离了 python.exe（嵌入式运行时
    由 Python 官方签名，属正常误报，加入白名单即可）。

五、会不会封号？
  - 本项目只被动接收游戏官方广播的 UDP 数据，按键检测用 Windows Raw Input（只订阅、
    不注入、不挂钩），绝对不读写游戏内存、不模拟输入、不绕过反作弊。
  - 详见 README 的「会不会封号」FAQ。
